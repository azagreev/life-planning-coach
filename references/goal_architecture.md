# Stage 2: Goal Architecture — Detailed Protocols

## Layer 1: BHAG (Big Hairy Audacious Goal)
**Time Horizon**: 10-25 years  
**Function**: North Star — направление, не точность

### Protocol
```
"Давайте найдём вашу 'большую цель' — то, к чему вы идёте 10-25 лет.

 Критерии эффективного BHAG:
 1. Ясный и вдохновляющий — понятен сразу
 2. Амбициозный — вызывает "вау, это смело"
 3. 50-70% вероятности успеха — не фантастика, но и не легко
 4. Связан с вашими ценностями и ikigai
 5. Действует как фильтр решений

 Вопросы для формирования:
 - Если бы вы могли гарантированно достичь одной вещи за 20 лет — что бы это было?
 - Что вы хотите, чтобы люди говорили о вашей жизни на вашем 80-летии?
 - Какой проблемой вы хотите заниматься десятилетия?
 - Что вы делаете, когда чувствуете себя живым? Как масштабировать это?

 Формат: 'Я [действие] [объект] [масштаб] [срок]'
 Пример: 'Я помогаю 1 млн людей найти свою профессию к 2045 году'

 Проверка: Если встать посреди ночи — этот BHAG зажжёт глаза?"
```

### Characteristics of Good Personal BHAG
| Property | Description | Example |
|----------|-------------|---------|
| Action-oriented | Не vision statement, а призыв к действию | "Написать 10 книг" vs "быть писателем" |
| Clear & compelling | Понятно за 10 секунд | "Построить школу в каждой деревне региона" |
| Bold | Вызывает реакцию "это невозможно" | "Пробежать марафон в 60 лет" |
| 50-70% success | Сложно, но не фантастика | Не "стать миллиардером" если вы бедны |
| Value-aligned | Связан с топ-3 ценностями | Если benevolence — BHAG про помощь другим |

## Layer 2: Life Themes (OKR-style, 1-3 years)

### Structure
```
3-5 Life Themes (Objectives) с Key Results каждый.

 Формат Objective: Качественный, вдохновляющий, временной
   - "Стать человеком, который бегает регулярно"
   - "Построить глубокие отношения с семьёй"
   - "Создать финансовую подушку безопасности"

 Формат Key Results: 3-5 количественных, измеримых результатов
   - KR1: "Пробежать 500 км за 2026 год"
   - KR2: "Пробежать полумарафон к сентябрю"
   - KR3: "Бегать 3 раза в неделю 40 из 52 недель"
```

### Personal OKR Best Practices
```
1. Максимум 3-5 Objectives (фокус!)
2. Максимум 3-5 Key Results на Objective
3. KR должны быть измеримы: числа, даты, boolean
4. Target: 0.6-0.7 achievement (не 1.0!)
5. Личные OKR — для роста, не для performance review
6. Проверяйте quarterly
7. Связывайте с BHAG: "Этот OKR приближает меня к BHAG как?"
```

### Scoring
```
0.0-0.3: Мало или никакого прогресса
0.4-0.6: Прогресс есть, но не достигли
0.7-0.9: Близко к цели, хороший результат
1.0: Полное достижение (возможно, цель была слишком лёгкой)
```

## Layer 3: 12-Week Quarter

### Why 12 Weeks Instead of Annual?
```
- Annual goals теряют срочность
- 12 weeks = достаточно для результата, коротко для фокуса
- 70% execution score — порог on-track (= квартальная планка)
- 4 таких цикла в году = 4 раза больше итераций
```

### Protocol
```
"Выберите 1-2 Objectives на 12 недель (не больше!)

 Для каждого Objective:
 1. Сформулируйте чётко (что будет через 12 недель?)
 2. Определите 3-5 Key Results (числовые)
 3. Определите weekly tactics (что делать каждую неделю?)
 4. Установите weekly score (0-100% execution)

 Execution Score Formula:
 - Сколько запланированных действий выполнено?
 - ≥ 70% = on-track, продолжай
 - 50-69% = можно улучшить
 - < 50% = пересмотри план или обстоятельства

 Week 13: Review + Celebration + Planning next 12 weeks"
```

## Layer 4: Weekly Priorities (3-5 Priorities)

### Ivy Lee Method (1918)
```
"Каждый вечер пишите 6 важных дел на завтра.
 Ранжируйте по важности.
 Утром начинайте с #1. Не переходите к #2, пока #1 не готово.
 Повторяйте каждый день."

 Адаптация для life planning:
 - 3-5 приоритетов на неделю (не 6)
 - Связаны с 12-Week Objectives
 - Максимум 1 "большой камень" в день
```

### Weekly Priority Template
```
Week of [date]:

BIG ROCKS (1-2 на неделю):
1. [ ] Приоритет #1 — связан с OKR/12-week goal
2. [ ] Приоритет #2 — связан с OKR/12-week goal

MEDIUM (2-3):
3. [ ] ...
4. [ ] ...

SMALL (quick wins):
5. [ ] ...

NOT THIS WEEK (explicitly deferred):
- ...
- ...
```

## Layer 5: Daily WOOP + Implementation Intentions

### WOOP Protocol (Oettingen)
**Эффект size: g = 0.336 (Wang et al., 2021), d = 0.65 (Gollwitzer & Sheeran, 2006)**

```
"Давайте сделаем WOOP для важной цели на сегодня/неделю.

 W — Wish (Желание):
 'Чего вы хотите?' (конкретно, реалистично)

 O — Outcome (Результат):
 'Какой лучший результат?' (представьте vividly, 30 секунд)

 O — Obstacle (Препятствие):
 'Какое главное внутреннее препятствие?' (ваша лень, страх, привычка)
 ВАЖНО: Не внешнее препятствие, а ВНУТРЕННЕЕ

 P — Plan (План):
 'Как вы преодолеете препятствие?' — if-then plan
 Формат: 'Если [препятствие], то я [действие]'

 Пример:
 W: Пробежать 5км сегодня утром
 O: Чувство энергии, гордость, чёткий ум
 O: Трудно встать, хочется 'ещё 5 минут'
 P: Если прозвенит будильник и я захочу отключить,
    то я встану, надену кроссовки и выйду на улицу
    (не думая — просто двигаюсь)"
```

### Implementation Intentions (Gollwitzer)
**Эффект size: d = 0.65 (94 studies)**

```
Формула: "Если [ситуация X], то я [действие Y]"

Типы if-then plans:
1. WHEN: "Когда наступит [время], то я [действие]"
2. WHERE: "Если я в [месте], то я [действие]"
3. WHAT: "Если я [ситуация], то я [конкретное действие]"

Примеры:
- "Когда я проснуссь (7:00), то я надену кроссовки"
- "Если я открою ноутбук, то сначала 90 минут глубокой работы"
- "Если я захочу перекусить вечером, то съем яблоко"
- "Когда будильник звонит в 21:00, то я закрою все экраны"

Ключи эффективности:
- Конкретный cue (время/место/ситуация)
- Конкретное действие (не абстрактное)
- Связывание с существующей привычкой (habit stacking)
```

## Integration: The Full Stack

```
25 YEARS: BHAG (1 goal)
    |
5 YEARS:  Milestones (3-5 milestones toward BHAG)
    |
3 YEARS:  Life Themes (3-5 OKRs)
    |
12 WEEKS: Execution Cycle (1-2 objectives, 3-5 KRs)
    |
1 WEEK:   3-5 priorities
    |
1 DAY:    WOOP + if-then plans + top 3 tasks
```

### Alignment Check
```
Каждый уровень должен поддерживать уровень выше:
- "Этот дневной WOOP приближает меня к weekly priority?"
- "Weekly priority приближает к 12-week objective?"
- "12-week objective приближает к 3-year theme?"
- "3-year theme приближает к BHAG?"

Если нет — корректировка needed.
```
