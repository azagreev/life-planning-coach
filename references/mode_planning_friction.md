# Planning Friction Audit — Smart Defaults & Template Library

> **When to use:** Пользователь жалуется, что "планирование не работает", постоянно срывает планы, чувствует вину за незавершённые задачи или избегает календаря.
> **Integration:** Использует энергетический профиль из `energy_scheduling.md`, события из `calendar_intelligence.md`, итоги из `weekly_review.md`.

---

## Core Framing

Планирование — не тест на усидчивость. Трение в системе — враг, а не человек.

> "Планирование должно чувствоваться как поддержка, а не ещё одна задача. Давайте найдём ваше трение и устраним его."

## 2. Day Templates

### Deep Work Day
```
08:00  Deep Work Block #1  (90 мин, пик энергии)
10:00  Буфер / переключение  (15 мин)
10:15  Deep Work Block #2  (90 мин)
12:00  Обед + отход от экрана  (60 мин)
---> Встречи только после 14:00, максимум 1
---> Вечер: без output-задач
```

### Meeting Day
```
09:00  Встреча #1  (25 мин)
09:35  Буфер  (15 мин)
09:50  Встреча #2  (25 мин)
10:20  Recovery Block  (30 мин, без экрана)
---> Максимум 4 встречи в день
---> Между встречами ≥15 мин буфера
---> После 16:00 — нет встреч
```

### Recovery Day
```
---> Нет output-целей
---> Только input: чтение, прогулка, рефлексия
---> Можно перенести задачи без вины
---> Использовать для перезагрузки после перегрузки
```

## 3. Smart Defaults

| Параметр | Default | Почему |
|----------|---------|--------|
| Встреча | 25 мин | Parkinson + recovery |
| Задача | 45 мин | Один помидор + буфер |
| Буфер между | 15 мин | Переключение контекста |
| Deep Work | 90 мин | Ультрадианный ритм |
| Планировать наперёд | Вечер пятницы | Снижает утренний load |
| Корректировка | 10% | Малые правки > большие смены |

---

## 4. 10% Adjustment Rule

Не меняйте систему кардинально. Начните с одного малого изменения:

- Слишком много встреч? → Уберите одну на этой неделе
- Нет буфера? → Добавьте 15 мин к одной паре событий
- Планируете утром? → Попробуйте вечер пятницы один раз

Малые правки работают лучше, потому что не активируют сопротивление.

---

## 5. Anti-Patterns

- ❌ Универсальные шаблоны "на все случаи жизни"
- ❌ Осуждение "просто планируй лучше"
- ❌ Сложные системы, требующие высокой исполнительной функции

---

## Science

- **Cognitive Load Theory** (Sweller): Каждое решение расходует ресурс. Smart defaults — offload.
- **Ultradian Rhythms** (Rossi): 90-мин циклы фокуса, 20-мин recovery.
- **Implementation Intentions** (Gollwitzer): "If-then" снижает friction на 2-3×.
- **Tiny Habits** (Fogg): Малые изменения > больших реформ.
