# Задача: Тестировщик — Персистентность данных v0.4.0

## Контекст

Ты — агент-тестировщик проекта `life-planning-coach`. Нужно проверить реализацию двухуровневой системы персистентности.

**Проект:** life-planning-coach (Claude Skill)  
**Версия:** v0.4.0  
**Критерии приёмки:** `references/acceptance_criteria_v0.4.md`  
**Реализация:** `SKILL.md` (после разработчика)

---

## Методология тестирования

Т.к. Claude Skill — это текстовые инструкции для LLM, "тестирование" = **симуляция сессий** и **проверка инструкций**.

### Метод 1: Инспекция (Review) — обязательно

Прочитать обновлённый `SKILL.md` и проверить:
- Все P0-критерии учтены в инструкциях?
- Инструкции понятны для Claude (конкретные, структурированные)?
- Нет противоречий с существующей методологией?
- Форматы файлов корректны (markdown, emoji, ASCII-бары)?

### Метод 2: Симуляция сессий (Simulation) — если возможно

Если есть доступ к Claude.ai (free plan):
- Установить skill → провести тестовые сессии
- Проверить поведение по критериям
- Зафиксировать результаты

### Метод 3: Чеклист проверки (Checklist) — обязательно

Пройти по каждому AC из `acceptance_criteria_v0.4.md` и отметить статус.

## Тестовые сценарии

### Сценарий A: Новый пользователь (Zero-Setup)

**Цель:** Проверить AC-1.1, AC-1.2, AC-1.5, AC-4.1, AC-4.3

**Шаги:**
1. Симулировать новый чат (no Memory, no Drive)
2. Проверить первые 3 ответа Claude:
   - [ ] Нет технических требований
   - [ ] Эмоционально безопасный тон
   - [ ] Начинает onboarding мягко
3. Провести сессию с конкретными целями:
   - "Хочу сменить работу"
   - "Моё препятствие — страх собеседований"
   - "Инсайт: страх меньше, чем я думал"
4. Проверить Memory:
   - [ ] Claude фиксирует цель в Memory
   - [ ] Claude фиксирует инсайт
5. Закрыть чат, открыть новый:
   - [ ] Claude распознаёт пользователя
   - [ ] Упоминает цель/контекст
   - [ ] НЕ требует state-dump

**Ожидаемый результат:** Пользователь проходит путь без трения.

---

### Сценарий B: Возвращающийся пользователь (Memory)

**Цель:** Проверить AC-1.3, AC-1.4, AC-4.1

**Шаги:**
1. Симулировать чат с Memory (предыдущая сессия была)
2. Первый ответ Claude:
   - [ ] Упоминает предыдущий контекст
   - [ ] Естественный диалог (не формальный)
   - [ ] Предлагает рассказать новости
3. Провести сессию → завершить:
   - [ ] Emotional summary присутствует
   - [ ] Memory обновлена
   - [ ] Gentle offer Drive (не навязчиво)

**Ожидаемый результат:** Плавное восстановление контекста.

---

### Сценарий C: Подключение Google Drive + Wiki

**Цель:** Проверить AC-2.1, AC-2.2, AC-2.3, AC-2.6, AC-2.8, AC-4.2

**Шаги:**
1. Подключить Google Drive connector в Claude.ai
2. Согласиться на сохранение
3. Проверить создание структуры:
   - [ ] Папка "Life Planning Coach Wiki" создана
   - [ ] Все подпапки присутствуют (00_Raw, 01_Wiki, etc.)
   - [ ] Hot_Cache.md создан с шаблоном
   - [ ] Index.md создан
   - [ ] Dashboard.md создан
   - [ ] README.md понятен пользователю
4. Провести сессию с диагностикой:
   - [ ] Raw-файл создан в 00_Raw/
   - [ ] Hot_Cache обновлён
   - [ ] Wiki-страницы обновлены
   - [ ] Dashboard обновлён
5. Проверить approval'ы:
   - [ ] ≤5 approval-кнопок за сессию
   - [ ] Batch-запись (не поштучно)
6. Открыть новый чат:
   - [ ] Claude читает Hot_Cache
   - [ ] Упоминает контекст из Hot_Cache
   - [ ] Время ответа <5 сек

**Ожидаемый результат:** Полная wiki-структура работает.

### Сценарий D: Graceful Degradation

**Цель:** Проверить AC-2.7, AC-4.3

**Шаги:**
1. Подключить Drive → провести сессию
2. Отключить Drive (или отозвать доступ)
3. Начать новую сессию:
   - [ ] Мягкое уведомление об отказе
   - [ ] Переключение на Memory mode
   - [ ] Сессия продолжается нормально
4. Провести сессию без Drive:
   - [ ] Данные сохранены в Memory
   - [ ] Нет паники/ошибок
5. Восстановить Drive:
   - [ ] Предложение синхронизировать

**Ожидаемый результат:** Пользователь не замечает проблемы.

### Сценарий E: Проверка форматов файлов

**Цель:** Проверить AC-2.4, AC-2.5, AC-3.2, AC-4.1

**Шаги:**
1. Открыть каждый тип файла в Google Drive:

   - [ ] Есть записи

**Ожидаемый результат:** Все файлы читаемы и полезны.
