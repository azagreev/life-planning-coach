# Markdown Tables for Coaching Conversations

> **When to use:** Пользователь просит структурировать план, оценить прогресс, провести обзор сфер жизни или запросил «таблицу» для наглядности.
> **Integration:** Генерируются conversationally по запросу пользователя. В SKILL.md таблиц нет — они подставляются в ответе, если стадия готова к структуре.

---

## Core Principle

Таблицы снижают когнитивную нагрузку для структурированных данных — если пользователь готов к структуре. На стадиях Precontemplation и Contemplation таблицы создают сопротивление: слишком рано, слишком жёстко.

> «Правильный инструмент в правильный момент.»

---

## 1. Template: Weekly Plan

Для стадии Preparation и выше. Помогает распределить приоритеты по дням без жёсткого давления.

```markdown
| Day | Priority | Time Block | Status |
|-----|----------|------------|--------|
| Mon |          |            |        |
| Tue |          |            |        |
| Wed |          |            |        |
| Thu |          |            |        |
| Fri |          |            |        |
| Sat |          |            |        |
| Sun |          |            |        |
```

> **Инструкция:** «Если захотите, можно распределить приоритеты по дням. Заполняйте только то, что чувствуете легко — остальное оставьте пустым.»

---

## 2. Template: Wheel of Life Review

11 доменов, оценка 1–10, одно действие на домен. Для стадии Action и выше.

```markdown
| Domain | Score | +/- since last | One Action |
|--------|-------|----------------|------------|
| 🏥 Здоровье | | | |
| 💰 Финансы | | | |
| 💼 Карьера | | | |
| 👨‍👩‍👧 Семья | | | |
| 💕 Романтика | | | |
| 👥 Дружба | | | |
| 🌱 Рост | | | |
| 🧘 Духовность | | | |
| 🎉 Отдых | | | |
| 🌍 Вклад | | | |
| 🏠 Дом | | | |
```

> **Инструкция:** «Можно оценить каждую сферу от 1 до 10 — так, как чувствуете прямо сейчас. Для одной сферы можно выбрать одно действие на неделю, если захотите.»

---

## 3. Template: Progress Check (OKR-style)

Для отслеживания целей и ключевых результатов. Стадия Preparation и выше.

```markdown
| Objective | Key Result | Current | Target | % |
|-----------|------------|---------|--------|---|
| | | | | |
| | | | | |
| | | | | |
```

> **Инструкция:** «Если захотите посмотреть прогресс по целям, можно заполнить текущее и целевое значение. Процент считается автоматически.»

---

## 4. Template: Course Correction

Что начать, прекратить, продолжить. Для стадии Action и Maintenance.

```markdown
| Area | Start | Stop | Continue |
|------|-------|------|----------|
| | | | |
| | | | |
| | | | |
```

> **Инструкция:** «Можно взглянуть на текущие направления: что хочется попробовать, что больше не работает, что стоит сохранить.»

---

## 5. Stage-Appropriate Rules

| Stage | Tables allowed | Why |
|-------|---------------|-----|
| Precontemplation | ❌ None | Слишком структурировано, вызывает сопротивление |
| Contemplation | ❌ None | Пользователь ещё не готов к планированию |
| Preparation | ✅ Weekly Plan, Progress Check | Лёгкая структура без давления |
| Action | ✅ All templates | Пользователь готов к инструментам |
| Maintenance | ✅ Progress Check, Course Correction | Фокус на устойчивости и корректировке |

---

## 6. Integration Notes

- **SKILL.md** не содержит таблиц — они генерируются динамически.
- Таблицы предлагаются, только если пользователь явно запросил структуру или если стадия позволяет.
- Всегда оставляйте пустые ячейки — пользователь заполняет сам, без принуждения.
- Если пользователь говорит «мне не нравятся таблицы» — honor autonomy, перейти к свободному тексту.
