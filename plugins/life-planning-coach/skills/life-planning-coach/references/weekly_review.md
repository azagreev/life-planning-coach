# Stage 3: Weekly Review & Retrospective — Detailed Protocols

## Overview

Еженедельный срез — критически важная практика. Исследования:
- **23% улучшение производительности** от 15 минут рефлексии (Di Stefano et al., Harvard)
- Незавершённые цели деградируют когнитивную производительность (Masicampo & Baumeister)
- Мониторинг прогресса напрямую увеличивает достижение целей (Harkin et al., Psychological Bulletin)

**Рекомендуемая длительность**: 45-60 минут  
**Минимальная версия**: 15 минут  
**Лучшее время**: Воскресенье вечер или понедельник утро

## Part 1: GTD Weekly Review (David Allen)

### Phase A: Get Clear (20 min)
```
1. Собрать все "входящие":
   □ Физические бумаги, заметки, визитки
   □ Email inbox -> zero
   □ Messenger/voice notes
   □ "Мысли из головы" (mind sweep — 5-10 минут)

2. Обработать каждый item:
   □ Сделать (если < 2 минут)
   □ Делегировать
   □ Отложить (с датой)
   □ Удалить

3. Пустой inbox = чистый разум
```

### Phase B: Get Current (15 min)
```
4. Review прошлой недели:
   □ Что было запланировано? Что выполнено?
   □ Какие обязательства пропущены?
   □ Какие встречи требуют follow-up?

5. Review следующей недели:
   □ Календарь на 1-2 недели вперёд
   □ Что нужно подготовить?
   □ Какие дедлайны приближаются?

6. Review списки:
   □ Active projects — по каждому: есть ли next action?
   □ Waiting for — нужны ли follow-ups?
   □ Someday/Maybe — что активировать?
```

### Phase C: Get Creative (10 min)
```
7. Review долгосрочных целей:
   □ BHAG всё ещё актуален?
   □ OKR на правильном пути?
   □ 12-week objective в фокусе?

8. Creative brainstorming:
   □ "Какие новые безумные идеи хочу попробовать?"
   □ Что вдохновляет на следующую неделю?
   □ Какие возможности я упускаю?
```

## Part 2: Scrum Retrospective

### Format Options (rotate weekly)

**Format A: Classic (5-10 min)**
```
What worked well this week?
What didn't work?
What will I start/stop/continue doing?
```

**Format B: Starfish (10 min)**
```
Keep:   Что работает? (продолжать)
Stop:   Что не работает? (прекратить)
Start:  Что хочу попробовать? (начать)
More:   Что усилить?
Less:   Что уменьшить?
```

**Format C: 4Ls (10 min)**
```
Liked:    Что понравилось? Что было приятным?
Learned:  Чему научился? Какие инсайты?
Lacked:   Чего не хватало? Каких ресурсов?
Longed:   Чего хотелось? Что сделало бы неделю лучше?
```

**Format D: Sailboat (15 min, visual)**
```
Island:  Куда мы плывём? (цель)
Wind:    Что нас толкает вперёд? (силы)
Anchors: Что нас тормозит? (препятствия)
Rocks:   Какие риски впереди?
Sun:     Ради чего это всё? (благодарность)
```

## Part 3: Progress Audit

### Lead vs Lag Measures

**Lag measures** — результаты, которые вы хотите:
- Сбросить 10 кг
- Накопить $50,000
- Закончить курс

**Lead measures** — действия, которые вы контролируете:
- Тренироваться 4 раза в неделю
- Откладывать 20% дохода
- Учиться 1 час в день

```
Audit по каждой 12-week objective:

Objective: [______________________________]

Lag measure:        [_____] / [_____] target
Lead measure:       [_____] / [_____] planned
Execution score:    [_____]%

Насколько я на пути? (1-10): [__]
Что мешало? [________________________]
Что помогало? [________________________]
```

### Confidence Ratings
```
По каждой цели спросить: "Насколько уверены, что достигнете? (1-10)"

8-10: Зелёная зона — продолжайте
5-7:  Жёлтая зона — что нужно для уверенности?
1-4:  Красная зона — полный пересмотр цели
```

## Part 4: Adjustment Protocol

### When to Pivot vs Persist (3-Gate Framework)

```
Gate 1: Data Check (2+ недели данных)
  └─ Есть ли достаточно данных для решения?
  └─ Нет -> Собирать ещё 1 неделю

Gate 2: Effort Check
  └─ Вы приложили максимум усилий?
  └─ Нет -> Усилить execution на неделю
  └─ Да -> Переход к Gate 3

Gate 3: Goal Validity Check
  └─ Эта цель всё ещё важна?
  └─ Эта цель всё ещё реалистична?
  └─ Контекст изменился?
  └─ Да на любой -> Pivot (изменить цель)
  └─ Нет -> Persist (продолжать, корректировать тактику)
```

### 10% Adjustment Rule
```
Вместо радикальных изменений — корректируйте на 10%:

- Цель слишком сложная? Уменьшите на 10%
- Слишком лёгкая? Увеличьте на 10%
- Недостаточно времени? Перераспределите 10%
- Execution низкий? Уберите 10% задач

Маленькие корректировки > больших скачков
```

### Seasonal Planning
```
Учитывайте сезонные циклы энергии:

Spring (Mar-May): Launch — идеально для новых начинаний
Summer (Jun-Aug): Push — интенсивная работа
Fall (Sep-Nov):   Harvest — сбор результатов, review
Winter (Dec-Feb): Rest — восстановление, планирование

Не планируйте "пуш" на декабрь.
Не планируйте "отдых" на сентябрь.
```

## Integrated Weekly Review Template (45-60 min)

```
WEEKLY REVIEW — Week of [______]

=== PART 1: GTD GET CLEAR (20 min) ===
□ Inbox zero (email, notes, messages)
□ Mind sweep (5-10 min — всё на бумагу)
□ Process all items

=== PART 2: LOOK BACK (10 min) ===
□ What worked? [________________________]
□ What didn't? [________________________]
□ What did I learn? [____________________]
□ What am I grateful for? [______________]

=== PART 3: PROGRESS AUDIT (10 min) ===
12-Week Objective: [______________________]
Lead measures this week: [_____] / [_____]
Execution score: [_____]%
Confidence (1-10): [__]

=== PART 4: LOOK AHEAD (10 min) ===
□ Next week's priorities (3-5)
□ Calendar review (конфликты? подготовка?)
□ WOOP for most important task
□ If-then plans for obstacles

=== PART 5: ADJUSTMENTS (5 min) ===
□ What to start/stop/continue?
□ Any pivots needed?
□ Celebration of wins (however small)
```

## 15-Minute Minimalist Version

```
5-MIN QUICK CLEAR:
□ Inbox scan (mark what needs attention)
□ 3-minute mind sweep

5-MIN REVIEW:
□ What was my win this week?
□ What was my biggest obstacle?
□ What one thing to improve next week?

5-MIN PLAN:
□ Top 3 priorities for next week
□ One if-then plan for expected obstacle
```
