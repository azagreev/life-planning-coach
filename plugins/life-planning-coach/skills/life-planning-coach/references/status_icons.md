# Status Icon System

> **When to use:** Пользователь запрашивает структурированный обзр прогресса, работает с Task Breakdown, или находится в стадии Action и предпочитает визуальную нотацию.
> **Integration:** Дополнение к `references/communication_style.md`. Используется только по запросу пользователя или в markdown-таблицах.

---

## Core Principle

Иконки снижают когнитивную нагрузку при сканировании статусов. Но они могут вызывать стресс у пользователей с высокой нейротичностью (High N). Поэтому — opt-in, с текстовым fallback.

---

## Icon Set

| Icon | Meaning | Text Fallback | When to use |
|------|---------|---------------|-------------|
| ⬜ | Todo / Not started | [ ] Не начато | Новая задача |
| 🔄 | In Progress | [~] В процессе | Начато, но не завершено |
| ✅ | Completed | [x] Выполнено | Чекпоинт пройден |
| ❌ | Cancelled | [-] Отменено | Задача отменена по решению пользователя |
| ⏸️ | Paused | [||] На паузе | Временно приостановлено |
| ⚠️ | At Risk | [!] Под угрозой | Риск невыполнения, требует внимания |

### Priority Colors (optional add-on)

| Icon | Priority | Use |
|------|----------|-----|
| 🔴 | P0 — Critical | Блокирует другие задачи |
| 🟡 | P1 — Important | Влияет на цель |
| 🟢 | P2 — Nice to have | Желательно, но не критично |

---

## Accessibility & Emotional Safety

- **Screen readers:** всегда дублировать текстом («⬜ Не начато» → "[ ] Не начато")
- **High N (High Neuroticism):** не показывать ❌ и ⚠️ без согласия — заменять на ⏸️ и 🔄
- **Precontemplation/Contemplation:** не использовать иконки статуса — создают ощущение "оценки"

---

## Example

```
📋 Weekly Priorities
⬜ Написать введение (🟡 P1)
🔄 Прочитать 2 статьи (🟢 P2) — 1 из 2 ✅
✅ Позвонить клиенту
⏸️ Подготовить презентацию — перенесено на след. неделю
```

---

## Quick Reference

```
Для пользователя High N:  ⬜ → 🔄 → ✅ (без ❌ и ⚠️)
Для пользователя High C:  ⬜ → 🔄 → ✅ → ❌/⏸️/⚠️ (полный набор)
В таблицах: всегда текстовый fallback в скобках
```
