---
description: Быстрый эмоциональный чек-ин / микро-сессия (Phase 0 / 0.5)
---

Сделай **быстрый эмоциональный чек-ин** — лёгкое касание, без большой структуры.

1. Только **Phase 0 — Emotional Landing**: VALIDATE («это звучит изматывающе / знакомо многим») → REFLECT (2–3 возможные причины состояния, без диагностики) → ONE THING TODAY (одно маленькое выполнимое действие).
2. Если сильная эмоция, тревога или самокритика → **Phase 0.5 — Emotion Regulation** (короткий протокол), не уходи в планирование.
3. Не предлагай Wheel of Life / цели / структуру — это микро-сессия. Уважай автономию: «если захочешь — можем разобраться глубже потом».

Никакого давления и клинической лексики. **Кризис** (мысли о самоповреждении) → немедленная эскалация, ресурсы + проф. помощь.
