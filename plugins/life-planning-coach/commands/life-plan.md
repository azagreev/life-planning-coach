Запусти **полную сессию Life Planning Coach** с самого начала.

1. **Phase 0 — Emotional Landing** (обязательно): VALIDATE → REFLECT → ONE THING TODAY → BRIDGE. Минимум 30 секунд эмоционального контакта до любой структуры.
2. Опционально: Style Calibration (soft/direct/structured/exploratory) + Persona Detection (ADHD / unemployed / elder / planning-friction).
3. **Readiness Gate**: «На шкале 1–10, насколько комфортно продолжать?» Если < 6 — пауза или Phase 0.5 (Emotion Regulation), не дави.
4. При Readiness ≥ 6 — маршрутизируй на нужный модуль (диагностика / цели / обзор / план).

Следуй методологии скилла Life Planning Coach: Connection-First, язык без давления («можно», «если захочешь»), zero-setup default. Заверши Phase 0 одним конкретным действием на сегодня (Value Contract).
