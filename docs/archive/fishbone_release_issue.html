🔗 Цепочка событий (Event Chain)

  1. core.filemode=false настроен в Git — система игнорирует различия в executable bit между рабочей копией и индексом.
  2. Файлы в WSL на NTFS получают права доступа 777, в то время как Git-индекс хранит 100644.
  3. Pytest запускает TestBuildScript, который вызывает python3 scripts/build-platform-skill.py.
  4. Скрипт сборки перезаписывает файлы platforms/{claude,grok,kimi}/SKILL.md, обновляя ctime и mtime.
  5. Git обновляет stat cache, записывая новые временные метки, но режим файла в кэше остаётся 777 (от ФС), а в индексе — 644.
  6. git diff-index --quiet HEAD -- сравнивает stat cache с индексом напрямую и видит расхождение по mode → возвращает 1 (dirty).
  7. git diff и git status уважают core.filemode=false и пропускают mode-only различия → выводят «чисто».
💡 Fix: git update-index --refresh — обновляет stat cache, устраняя расхождение.
🛡️ Prevention: Добавить git update-index --refresh в scripts/release.sh перед проверкой git diff-index.
