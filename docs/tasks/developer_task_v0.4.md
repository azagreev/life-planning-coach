## Задачи

### Эпик 1: Обновить SKILL.md — Уровень 1 (Zero-Setup)

**Файл:** `SKILL.md`

**Что добавить:**

1. **Раздел "Персистентность данных"** (новый, после методологии):
   - Принцип: Zero-Setup Default
   - Описание Режима 1 (Memory) и Режима 2 (Drive+Wiki)
   - End-of-Session Protocol
   - Graceful Degradation

2. **Инструкции для Claude Memory**:
   - Какие факты записывать в Memory (цели, фокус, инсайты, контекст пользователя)
   - Как формулировать: "Запомни: пользователь [имя] работает над [цель], текущий прогресс [X], препятствие [Y]"
   - Memory — автоматический, но Claude должен акцентировать ключевые факты

3. **Протокол восстановления контекста (Memory mode)**:
   - Если Memory есть данные → emotional check-in: "Привет! Помню, ты работал над [цель]. Как продвигается?"
   - Если Memory нет данных → cold start: "Привет! Мы с тобой уже работали? Если да — расскажи, над чем фокусировались"
   - НИКОГДА не требовать state-dump, копирование, вставку

4. **End-of-Session Protocol**:
   - Emotional summary
   - Обновление Memory (авто)
   - Gentle offer Google Drive (не чаще 1 раза на 3 сессии)

5. **Убрать из onboarding'а**:
   - Любые упоминания "настрой Google Drive" в первых 3 сообщениях
   - Любые требования скопировать/вставить state
   - Технические инструкции в начале диалога

### Эпик 2: Обновить SKILL.md — Уровень 2 (Drive + LLM Wiki)

**Файл:** `SKILL.md`

**Что добавить:**

1. **Структура wiki на Google Drive** (справочная секция):
   - Полная иерархия папок и файлов
   - Назначение каждой папки (00_Raw, 01_Wiki, 02_Instructions, etc.)
   - Claude НЕ создаёт структуру сам — инструкции для пользователя как подключить Drive
   - Wait: на самом деле Claude через connector МОЖЕТ создавать файлы. Нужны инструкции для Claude КАК создавать.

2. **Форматы файлов** (шаблоны в SKILL.md):
   - `Hot_Cache.md` — шаблон с секциями, пример на русском
   - `Index.md` — структура оглавления
   - `Dashboard.md` — шаблон для пользователя
   - `Raw/session.md` — шаблон записи сессии
   - Все шаблоны с emoji, ASCII-прогресс-барами, русским языком

3. **Протокол работы с Drive**:
   - При старте: читать Hot_Cache.md → Index.md
   - Во время сессии: накапливать изменения в памяти
   - В конце: batch-запись (Raw + Hot_Cache + wiki + Dashboard) — ≤5 approval'ов
   - Graceful degradation: Drive недоступен → переключиться на Memory

4. **CLAUDE.md** (файл в wiki):
   - Инструкции для Claude как работать с wiki
   - Правила обновления (append-only для Raw, перезапись для Hot_Cache)
   - Токен-бюджеты (Hot_Cache <1000 токенов)

## Ограничения и осторожность

1. **Язык:** Все инструкции для Claude — на английском (SKILL.md пишется на английском, т.к. это system prompt). Но примеры файлов — на русском (контент для пользователя).
2. **Не усложняй:** Минимальные изменения. Не переписывай всю методологию — только добавь persistence layer.
3. **Не требуй от пользователя:** Никаких технических действий в default mode.
4. **Тестировать нельзя:** Разработчик не имеет доступа к Claude Pro. Полагайся на точность инструкций.
