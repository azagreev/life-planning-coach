## Формула расчёта

```
RAW_SCORE = (energy × 4.0) + (sleep × 2.5) + (clarity × 2.0) +
            (motivation × 1.0) + ((10 - stress) × 0.5)

ENERGY_SCORE = RAW_SCORE × (100 / 85)  # Нормализация к 0-100

Где максимум RAW_SCORE = (10×4) + (10×2.5) + (10×2) + (10×1) + (9×0.5) = 85
```

| Вес | Компонент | Почему такой вес |
|-----|-----------|-----------------|
| 0.40 | Энергия | Главный субъективный показатель |
| 0.25 | Сон | Recovery correlate #1 |
| 0.20 | Ясность мыслей | Когнитивный recovery (уникально для productivity) |
| 0.10 | Мотивация | Драйв, не требующий энергии |
| 0.05 | Стресс (инверт.) | Модификатор, не главный фактор |

## Baseline calculation

**[SKILL-READY]** После 7 дней данных:

```
Personal Baseline = среднее Energy Score за 7 дней
Personal StdDev = стандартное отклонение

Trend: сегодня vs baseline
  ↑ +10%: "Энергия выше вашего обычного"
  → ±5%: "Энергия в пределах нормы"
  ↓ -10%: "Энергия ниже обычного — бережный режим"
```

**Важно:** Сравнение только с **личным** baseline, не с популяционной нормой.

## Post-task feedback

**[SKILL-READY]** После каждого focus block / body doubling session:

```
✅ [Задача] выполнена!

Была ли энергия в это время такой, как я прогнозировал?

[⚡ Да, точно] [😐 Ниже] [🚀 Выше] [🤷 Не знаю]

Это поможет мне точнее прогнозировать.
```

**Использование feedback:**
- Накапливается correlation: predicted energy vs actual
- Через 14+ дней → персонализированные пороги
- Не используется для оценки пользователя — только для калибровки
