# Критерии приёмки: Персистентность данных v0.4.0

## Версия: 0.4.0
## Дата: 2026-05-16
## Статус: Draft → Ready for Development

---

## Контекст

На основе `references/persistence_research_plan.md` v0.4.0. Двухуровневая архитектура:
- **Уровень 1**: Zero-Setup (Claude Memory + контекст + естественный диалог)
- **Уровень 2**: Google Drive + LLM Wiki (Karpathy pattern, opt-in)

Каждый критерий имеет: ID, описание, ожидаемый результат, способ проверки, приоритет (P0 = блокер, P1 = важно, P2 = желательно).

---

## Эпик 1: Zero-Setup Foundation (Уровень 1)

### AC-1.1: Onboarding без технических требований [P0]

**Условие:** Новый пользователь открывает скилл в новом чате Claude.ai (free plan, без Google Drive).

**Ожидаемый результат:**
- Claude приветствует пользователя естественным языком
- НЕ требует настройки Google Drive, OAuth, копирования state-dump'ов
- НЕ спрашивает "есть ли у тебя сохранённый state"
- Начинает диагностику Wheel of Life или мягкий onboarding в течение 3 сообщений

**Проверка:**
- Запустить новый чат → проверить первые 3 ответа Claude
- Must: ни одного упоминания "Drive", "сохранение", "state", "dump", "OAuth"
- Must: эмоционально безопасный тон (не "настройся", а "давай разберёмся")

---

### AC-1.2: Claude Memory записывает ключевые факты [P0]

**Условие:** В процессе сессии пользователь называет цели, прогресс, инсайты.

**Ожидаемый результат:**
- Claude явно или неявно фиксирует в Memory:
  - Топ-3 цели пользователя
  - Текущий фокус/препятствие
  - Ключевые инсайты
  - Контекст пользователя (сфера, боли, сильные стороны)

**Проверка:**
- Провести сессию 15+ минут с конкретными целями
- Открыть новый чат → спросить "что ты помнишь обо мне?"
- Must: Memory содержит ≥3 ключевых факта из сессии
- Must: факты релевантны (не галлюцинации)

---

### AC-1.3: Восстановление контекста — естественный диалог [P0]

**Условие:** Пользователь возвращается в новый чат после 1+ сессий (Memory есть данные, контекста нет).

**Ожидаемый результат:**
- Claude приветствует с распознаванием: "Привет! Помню, ты работал над [цель]"
- НЕ требует технического bootstrap'а ("вставь свой state-dump")
- Предлагает мягко: "Расскажи, что нового с [дата/событие]?"
- Если пользователь описывает прогресс — Claude подхватывает и продолжает

**Проверка:**
- Сессия 1: установить цель "найти работу", прогресс "отправил 3 резюме"
- Закрыть чат, открыть новый
- Must: Claude упоминает цель "найти работу" в первом ответе
- Must: нет фраз "вставь", "скопируй", "state", "dump"
- Must: предложение рассказать новости — естественное, не формальное

---

### AC-1.4: End-of-Session Protocol [P1]

**Условие:** Сессия подходит к концу (пользователь говорит "до свидания", "спасибо", или 30+ минут диалога).

**Ожидаемый результат:**
- Claude делает emotional summary: "Сегодня мы обсудили [темы], ты решил [действия]"
- Обновляет Memory (автоматически, без действий пользователя)
- Мягко предлагает Google Drive: "Если хочешь, чтобы данные сохранялись надёжнее — могу подключить Google Drive. Это один клик."
- Предложение НЕ навязчивое (не капсом, не в каждой сессии, макс 1 раз на 3 сессии)

**Проверка:**
- Провести сессию → сказать "спасибо, до свидания"
- Must: emotional summary присутствует
- Must: предложение Drive — мягкое, опциональное
- Must: предложение не повторяется в подряд идущих сессиях

---

### AC-1.5: Cold Start Recovery [P1]

**Условие:** Новый чат, НЕТ Memory данных (первый раз, или Memory сброшена).

**Ожидаемый результат:**
- Claude спрашивает: "Привет! Мы с тобой уже работали? Если да — поделись, над чем фокусировались"
- Если пользователь говорит "да, искал работу" — Claude продолжает оттуда
- Если пользователь говорит "нет" — мягкий onboarding (не полная диагностика сразу)
- НЕ начинает с "вставь свой state-dump"

**Проверка:**
- Симулировать нового пользователя без Memory
- Must: первый вопрос — про предыдущий опыт, не про техническую настройку
- Must: продолжение после "искал работу" — без повторной диагностики

## Эпик 2: Google Drive + LLM Wiki (Уровень 2)

### AC-2.1: Создание структуры wiki на Google Drive [P0]

**Условие:** Пользователь подключил Google Drive connector в Claude.ai и согласился на сохранение.

**Ожидаемый результат:**
- Claude создаёт папку "Life Planning Coach Wiki" в корне Google Drive
- Внутри создаёт полную структуру:
  - `00_Raw/` (пустая)
  - `01_Wiki/` с подпапками: Concepts, Frameworks, User_Progress, Decisions, Sources
  - `01_Wiki/Hot_Cache.md` (с шаблоном)
  - `01_Wiki/Index.md` (с шаблоном)
  - `02_Instructions/CLAUDE.md`
  - `03_Dashboard/Progress_Dashboard.md`
  - `04_References/Glossary.md`, `FAQ.md`
  - `05_Archive/`
  - `README.md`
  - `CHANGELOG.md`
- Все файлы — Google Docs формат или .md (readable)

**Проверка:**
- Подключить Drive → согласиться
- Must: папка "Life Planning Coach Wiki" появилась в Google Drive
- Must: все перечисленные файлы/папки присутствуют
- Must: `Hot_Cache.md` содержит шаблонные секции (цели, фокус, инсайты)
- Must: `README.md` объясняет пользователю, что это и зачем

---

### AC-2.2: Запись Raw-сессии [P0]

**Условие:** Сессия завершена, Drive подключён.

**Ожидаемый результат:**
- Claude создаёт файл `00_Raw/session-YYYY-MM-DD-HHMM.md`
- Содержит: дата/время, ключевые темы, цели, инсайты, действия
- Формат: markdown, русский язык
- Raw файл НЕ перезаписывается (append-only для истории)

**Проверка:**
- Провести сессию → завершить
- Must: в `00_Raw/` появился новый файл с датой сессии
- Must: файл содержит ≥3 ключевых факта из сессии
- Must: старые Raw-файлы не изменились

---

### AC-2.3: Обновление Hot_Cache [P0]

**Условие:** Сессия завершена, Drive подключён.

**Ожидаемый результат:**
- Claude обновляет `01_Wiki/Hot_Cache.md`
- Содержит ~500 слов (не более 800)
- Секции: Активные цели, Текущий фокус, Инсайты недели, Ближайшие события, Контекст пользователя
- Дата обновления внизу файла
- Токен-объём файла: <1000 токенов

**Проверка:**
- Провести сессию с конкретными целями → завершить
- Must: `Hot_Cache.md` обновлён
- Must: цели из сессии отражены в Hot_Cache
- Must: размер файла — 300-800 слов (не менее 200, не более 1000)
- Must: дата обновления — текущая

---

### AC-2.4: Обновление wiki-страниц [P1]

**Условие:** В сессии обсуждались цели, Wheel of Life, или другие структурированные данные.

**Ожидаемый результат:**
- Если обсуждались цели → обновить `01_Wiki/User_Progress/Goals.md`
- Если обсуждался Wheel of Life → обновить `01_Wiki/User_Progress/Wheel_of_Life_History.md`
- Если новый инсайт → добавить в соответствующую страницу или Hot_Cache
- Wiki-страницы используют markdown-таблицы, ASCII-прогресс-бары, emoji

**Проверка:**
- Провести сессию с диагностикой Wheel of Life (оценить 8 сфер)
- Завершить сессию
- Must: `Wheel_of_Life_History.md` содержит новые оценки
- Must: `Goals.md` обновлён если обсуждались цели
- Must: формат — читаемый markdown (таблицы, прогресс-бары)

---

### AC-2.5: Обновление Dashboard [P1]

**Условие:** Сессия завершена, Drive подключён.

**Ожидаемый результат:**
- Claude обновляет `03_Dashboard/Progress_Dashboard.md`
- Содержит: текущие цели с прогресс-барами, Wheel of Life summary, инсайт недели, ближайшие события
- Язык: русский, с emoji
- Пользователь может открыть файл и понять свой прогресс без объяснений

**Проверка:**
- Провести сессию → завершить
- Must: Dashboard обновлён
- Must: содержит ≥3 секции (цели, прогресс, события)
- Must: прогресс-бары в ASCII-формате
- Must: язык — русский, понятный не-технарю

---

### AC-2.6: Чтение Hot_Cache при старте сессии [P0]

**Условие:** Пользователь начинает новую сессию, Drive подключён.

**Ожидаемый результат:**
- Claude читает `Hot_Cache.md` ПЕРВЫМ делом
- Затем читает `Index.md`
- На основе Hot_Cache строит emotional summary для пользователя
- НЕ перечитывает все Raw-файлы
- Токены на загрузку контекста: <1500 (Hot_Cache + Index)

**Проверка:**
- Провести сессию с целями → завершить
- Открыть новый чат (Drive подключён)
- Must: Claude упоминает цели из Hot_Cache в первом ответе
- Must: время до первого ответа <5 сек (не читает много файлов)
- Must: нет упоминаний "читаю все твои старые сессии"

---

### AC-2.7: Graceful Degradation при отказе Drive [P0]

**Условие:** Drive был подключён, но connector временно недоступен (geo-block, revoke, ошибка).

**Ожидаемый результат:**
- Claude уведомляет: "Сейчас не могу подключиться к Google Drive. Работаем в обычном режиме, данные сохраняются в памяти разговора."
- Переключается на Уровень 1 (Memory + контекст)
- НЕ теряет данные текущей сессии
- НЕ паникует, НЕ требует действий от пользователя
- При восстановлении Drive — предлагает синхронизировать

**Проверка:**
- Симулировать отказ Drive (отключить connector или сменить аккаунт)
- Начать сессию
- Must: сообщение об отказе — мягкое, без технических деталей
- Must: сессия продолжается нормально
- Must: данные сессии сохранены в Memory

---

### AC-2.8: Batch update и минимум approval'ов [P1]

**Условие:** Сессия завершена, Drive подключён.

**Ожидаемый результат:**
- Claude группирует операции записи (не пишет файл за файлом с паузами)
- Количество approval-кнопок за сессию: ≤5
- Все записи в Raw + Hot_Cache + wiki + Dashboard делаются в рамках end-of-session protocol
- НЕ пишет на диск в середине сессии (только в конце или по явному запросу)

**Проверка:**
- Провести полную сессию → завершить
- Must: approval-кнопок за всю сессию ≤5
- Must: запись на диск — только в конце (не в середине диалога)
- Must: запись группирована (не 10 отдельных approval'ов)

**Проверка:**

## Эпик 4: UX и психологическая безопасность

### AC-4.1: Язык общения [P0]

**Ожидаемый результат:**
- Все сообщения Claude — на русском языке (основной язык пользователя)
- Технические термины (wiki, cache, connector) — НЕ используются в общении с пользователем
- Пользователь видит: "сохраняю твой прогресс", а не "обновляю Hot_Cache"

**Проверка:**
- Провести сессию с Drive
- Must: ни одного упоминания "Hot_Cache", "wiki", "Index", "Raw" в диалоге
- Must: термины заменены на человеческие: "твои цели", "твой прогресс", "заметки"

---

### AC-4.2: Пользователь контролирует свои данные [P1]

**Ожидаемый результат:**
- Данные хранятся в Google Drive ПОЛЬЗОВАТЕЛЯ (не на серверах Anthropic)
- Пользователь может открыть файлы в Drive и прочитать
- Файлы на русском, с понятными названиями
- Пользователь может удалить папку wiki в любой момент

**Проверка:**
- Must: файлы в Drive пользователя, доступны через drive.google.com
- Must: названия файлов понятны ("Мои цели", "Прогресс", а не "state_v2.json")
- Must: удаление папки не ломает скилл (graceful fallback)

---

### AC-4.3: Эмоциональная безопасность [P0]

**Ожидаемый результат:**
- При ошибках (Drive недоступен, данные потеряны) — Claude НЕ паникует
- Сообщения об ошибках: мягкие, с фокусом на продолжении работы
- Нет фраз "ошибка системы", "данные повреждены", "критический сбой"

**Проверка:**
- Симулировать ошибки: отключить Drive, удалить файлы, отозвать доступ
- Must: все сообщения — поддерживающие, без паники
- Must: предложение продолжить работу присутствует
