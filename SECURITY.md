# Security Policy

## Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| 0.1.x  | ✅ Активная |
| < 0.1  | ❌ Не поддерживается |

## Что считается уязвимостью

- Утечка encryption key или credentials через логи / исключения
- Обход Fernet-шифрования токенов
- XSS или инъекции в dashboard
- Небезопасное хранение OAuth токенов

## Что НЕ считается уязвимостью

- Отсутствие шифрования при передаче к Google (Google API использует HTTPS)
- Локальный доступ к зашифрованным файлам при наличии ключа
