# Альтернативы тестирования для разработчика из России

> **Контекст:** У вас нет подписки Claude Pro, и claude.ai недоступен из России. Вы не можете протестировать MCP-интеграцию с Google Calendar самостоятельно. Этот документ — практический гид, как получить обратную связь по скиллу другими путями.

---

## 1. Где найти тестировщиков за рубежом

### Ближний круг (приоритет — высокий)
- **Друзья и коллеги за границей** — лучший вариант. Доверие есть, мотивация помочь выше.
- **Знакомые из IT** — люди с подпиской Claude Pro уже есть в вашем окружении, просто вы не знаете об этом.

### Telegram-сообщества (приоритет — высокий)
- Каналы и чаты про ИИ: запросите помощь в обмен на упоминание в README или небольшое вознаграждение.
- Русскоязычные чаты в Европе, Грузии, Армении, Казахстане — там много людей с доступом к Claude Pro.
- Поисковые запросы: «Claude AI чат», «AI tools сообщество», «продуктовые менеджеры».

### Reddit (приоритет — средний)
- Сабреддит [r/ClaudeAI](https://reddit.com/r/ClaudeAI) — активное сообщество, ~50k участников.
- Сабреддит r/artificial — шире аудитория, но меньше концентрация пользователей Claude.
- Формат поста: «I built a life planning skill for Claude — need beta testers» + ссылка на GitHub.
- Укажите, что нужен Claude Pro (это отфильтрует нецелевых откликов).

### Discord-серверы (приоритет — средний)
- Сервер Anthropic (официальный) — канал #community-projects или #showcase.
- Сервер «Latent Space» и другие AI-community — аудитория техническая, понимает, что такое skills.
- Локальные продуктовые Discord'ы — запросите помощь у коллег.

### Совет по формату обращения
Не пишите «потестируйте, пожалуйста». Пишите конкретно:
- Что нужно протестировать (3–4 пункта).
- Сколько времени займёт (20–40 минут на первую сессию).
- Что получит тестировщик (бесплатный life coach, понимание своих целей).
- Что нужно вам (отчёт о багах, впечатления).

## 2. Что отправлять удалённому тестировщику

### Пакет файлов (один архив или ссылка на GitHub)
```
life-planning-coach/
├── README.md                 # общее описание
├── SKILL.md                  # для просмотра содержимого скилла
├── life-planning-coach.skill # файл для загрузки в Claude
├── life-planning-dashboard.html # дашборд (открывается в браузере)
└── references/               # для глубокого погружения
    ├── diagnostic_methods.md
    ├── goal_architecture.md
    ├── weekly_review.md
    └── calendar_integration.md
```

### QA-чеклист (приложите отдельным файлом или в сообщении)
Скопируйте ниже в файл `QA_CHECKLIST.md` и отправьте тестировщику:

```markdown
## QA Чеклист для тестировщика

### Stage 1: Диагностика
- [ ] Скилл активировался на фразу "помоги спланировать жизнь" или `/life-planning-coach`
- [ ] Первое сообщение — Emotional Landing (валидация чувств, а не вопросы)
- [ ] Нет слов "надо", "должен", "нужно" в первых 10 сообщениях
- [ ] Wheel of Life: 8 сфер, оценки 1–10, радарная диаграмма или текстовая визуализация
- [ ] Values Clarification: 10 ценностей Schwartz с ранжированием
- [ ] Designing Your Life: Workview + Odyssey Plans (минимум 3 плана)
- [ ] Ikigai + Life Story: пиковые моменты, провалы, переломы

### Stage 2: Архитектура целей
- [ ] BHAG: одна большая цель на 10–25 лет сформулирована
- [ ] Life Themes: 3–5 тем в формате OKR (objective + key results)
- [ ] 12-Week Quarter: конкретные цели и измеримые результаты
- [ ] Weekly Priorities: 3–5 приоритетов на неделю
- [ ] Daily WOOP: Wish + Outcome + Obstacle + Plan

### Stage 3: Еженедельный срез
- [ ] GTD: Get Clear / Get Current / Get Creative
- [ ] Scrum Retro: что работало / не работало / что меняем
- [ ] Progress Audit: lead vs lag measures
- [ ] Adjustment Protocol: корректировка или подтверждение плана

### Stage 4: Дашборд
- [ ] Команда "покажи дашборд" генерирует HTML-файл
- [ ] Файл открывается в браузере без интернета
- [ ] 3 таба: Обзор, Ретроспектива, Цели
- [ ] Wheel of Life Radar отображается корректно

### Stage 5: Google Calendar (требуется Pro + MCP)
- [ ] Подключение Google Calendar MCP через Settings → Capabilities
- [ ] Создание Weekly Review — повторяющееся событие по воскресеньям
- [ ] Создание WOOP-напоминания — ежедневное событие
- [ ] Создание Time Block на конкретное время
- [ ] Проверка Free Slots — запрос "когда я свободен?"

### Общее качество
- [ ] Тон: поддерживающий, без давления, без осуждения
- [ ] Можно пропустить любой вопрос или прервать сессию
- [ ] Данные можно экспортировать через "Экспортируй мои данные в JSON"
- [ ] Скилл предлагает перерыв после 8–10 вопросов
```

### Инструкция по установке (скопируйте из README)
1. Войти в [claude.ai](https://claude.ai) (нужна подписка Pro).
2. Settings → Capabilities → Skills → Upload skill.
3. Выбрать `life-planning-coach.skill`.
4. Написать триггер-фразу: «помоги спланировать жизнь».

## 3. Локальное тестирование без MCP (Stages 1–4)

**Главный принцип:** Stages 1–4 работают полностью в текстовом режиме без календаря. Вы можете протестировать их через любой доступный LLM, в том числе через API или локальные модели.

### Как это работает
Скилл — это текстовый инструктаж для AI-агента. Вся логика диагностики, постановки целей и ретроспективы описана в `SKILL.md`. MCP нужен только для Stage 5 (Google Calendar).

### Метод тестирования: "Ролевая симуляция"
1. Откройте `SKILL.md` в редакторе.
2. Скопируйте содержимое в промпт к любому доступному LLM.
3. Напишите: «Ты — life planning coach. Следуй инструкциям из этого документа. Я готов начать.»
4. Отвечайте как обычный пользователь.

### Что можно проверить без MCP

| Что тестируем | Как проверить | Ожидаемый результат |
|---|---|---|
| Emotional Landing | Напишите: «Я чувствую, что жизнь проходит мимо» | Валидация чувств, НЕ вопросы 1–10 |
| Wheel of Life | Согласитесь на диагностику | 8 сфер с оценками, визуализация |
| Values Clarification | Пройдите парное сравнение | 10 ценностей с весами |
| BHAG + OKR | Завершите Stage 1 | Многоуровневая система целей |
| Weekly Review | Скажите: «хочу сделать еженедельный срез» | GTD + Scrum Retro |
| Дашборд | Попросите: «покажи дашборд» | HTML-код для сохранения в файл |
| Тон и язык | Ведите диалог | Нет «надо/должен/нужно», есть «можно/если захотите» |

### Ограничения текстового тестирования
- Данные не сохраняются между сессиями (нет conversation state).
- Нет интеграции с календарём.
- HTML-дашборд нужно сохранять и открывать вручную.
- Триггерные фразы работают только в Claude.ai.

**Но:** Вся логика, структура вопросов, качество эмоционального контакта и построение целей проверяются полностью.

## 4. Можно ли тестировать через Claude API?

**Короткий ответ: Нет, но есть нюансы.**

### Почему не работает
- **MCP (Model Context Protocol)** доступен **только** в веб-интерфейсе claude.ai.
- Через API нет поддержки skills, нет MCP-коннекторов, нет Google Calendar интеграции.
- Файл `.skill` загружается в настройки аккаунта, а не передаётся через API.

### Что МОЖНО сделать через API
Если у вас есть доступ к Claude API ( Anthropic API ):
1. Скопируйте содержимое `SKILL.md` в system prompt.
2. Используйте API для текстового диалога.
3. Это эквивалентно тестированию Stages 1–4 (без MCP).

**Пример кода (Python):**
```python
import anthropic

with open("SKILL.md", "r") as f:
    skill_content = f.read()

client = anthropic.Anthropic(api_key="YOUR_API_KEY")

message = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=4096,
    system=skill_content,
    messages=[
        {"role": "user", "content": "Я чувствую, что жизнь проходит мимо, помоги разобраться"}
    ]
)

print(message.content[0].text)
```

### Практический вывод
API-подход хорош для:
- Тестирования текстовой логики скилла.
- Проверки структуры промптов.
- Автоматизации юнит-тестов (эталонные ответы).

API-подход НЕ подходит для:
- Тестирования триггерных фраз (они работают на уровне платформы Claude.ai).
- Тестирования MCP и Google Calendar.
- Проверки UX загрузки skills.

## 5. Доступ из России: VPN и прокси

> **Строго информационная заметка.** Соблюдайте законодательство РФ и правила сервисов, которыми пользуетесь.

### Ситуация
- `claude.ai` и `anthropic.com` ограничены для доступа из России.
- Для использования Claude Pro требуется иностранная карта (РФ-карты не принимаются).

### Технические варианты (информационно)
- **VPN** — позволяет открыть сайт, но НЕ решает проблему с оплатой.
- **Зарубежная SIM / eSIM** — для SMS-верификации аккаунта.
- **Иностранная карта** (друзья/родственники за границей) — единственный способ оплатить Pro.

### Рекомендация
Если у вас нет возможности оформить Claude Pro — сосредоточьтесь на привлечении удалённых тестировщиков (разделы 1–2). Это быстрее, дешевле и не требует обхода ограничений.
