## Открытые баги

### BUG-001: Dashboard показывает 8 сфер Wheel of Life вместо 11
- **Приоритет:** P1
- **Статус:** open
- **Найден:** 2026-05-17
- **Версия:** v0.6.1
- **Owner:** @azagreev
- **Файлы:** `life-planning-dashboard.html`

**Описание:**
HTML Dashboard (`life-planning-dashboard.html`) содержит старую реализацию Wheel of Life с 8 сферами. В v0.6.0 количество сфер было расширено до 11, но дашборд не обновлён.

**Expected:**
Дашборд отображает 11 сфер Wheel of Life, соответствующих AC-10 v0.7:
1. Здоровье и физическая форма
2. Финансы и материальное благополучие
3. Карьера и работа
4. Семья и близкие
5. Романтика и партнёрство
6. Дружба и социальные связи
7. Личностный рост и обучение
8. Духовность, смысл и ценности *(обязательный)*
9. Отдых, хобби и радость
10. Вклад в общество и наследие
11. Дом и окружение

**Actual:**
Дашборд отображает только 8 сфер:
1. Здоровье и фитес (`health`)
2. Карьера и бизнес (`career`)
3. Финансы (`finances`)
4. Отношения (`romance`)
5. Семья и друзья (`family`) — склеены в одну
6. Личный рост (`growth`)
7. Развлечения (`fun`)
8. Окружение (`environment`)

**Missing domains:**
- ❌ Духовность, смысл и ценности (8)
- ❌ Вклад в общество и наследие (10)
- ❌ Романтика отделена от Семьи? — нет, romance есть, но Семья и Друзья склеены
- ⚠️ Family/Friends не разделены на Семья (4) и Дружба (6)

**Steps to reproduce:**
1. Открыть `life-planning-dashboard.html` в браузере
2. Найти раздел "Wheel of Life" (или радарную диаграмму)
3. Посчитать количество секторов/меток

**Root cause:**
Дашборд не обновлялся после расширения Wheel of Life с 8 до 11 сфер в v0.6.0. Константа `WHEEL_SPHERES` в JS содержит 8 элементов.

**Affected code:**
```javascript
// life-planning-dashboard.html:903
const WHEEL_SPHERES = [
  { id: 'health', name: 'Здоровье и фитес', ... },      // 1
  { id: 'career', name: 'Карьера и бизнес', ... },      // 2
  { id: 'finances', name: 'Финансы', ... },             // 3
  { id: 'romance', name: 'Отношения', ... },            // 4 (romance)
  { id: 'family', name: 'Семья и друзья', ... },        // 5 (family+friends merged)
  { id: 'growth', name: 'Личный рост', ... },           // 6
  { id: 'fun', name: 'Развлечения', ... },              // 7
  { id: 'environment', name: 'Окружение', ... },        // 8
];
```

**Impact:**
- Пользователь видит неполную картину баланса жизни
- Несоответствие между скиллом (11 сфер в диалоге) и дашбордом (8 сфер)
- Нарушение AC-10 (Wheel of Life — 11 доменов)

**Proposed fix:**
1. Расширить `WHEEL_SPHERES` до 11 элементов
2. Разделить `family` → `family` (Семья и близкие) + `social` (Дружба и социальные связи)
3. Добавить `spirituality` (Духовность, смысл и ценности)
4. Добавить `contribution` (Вклад в общество и наследие)
5. Обновить subtitle: "Баланс 8 сфер жизни" → "Баланс 11 сфер жизни"
6. Обновить радарную диаграмму (12 секторов → 22, или адаптировать визуализацию)
7. Проверить gauges (сейчас 3 gauges, должно покрывать все 11)

**Blocked by:**
- Нет блокеров. Можно начать сразу.
